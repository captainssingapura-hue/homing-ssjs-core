# The resolution's fixture

## Control

Something the user works.

## Button

A control pressed to act once.

## Container

Something that holds others.

## PlainButton

A button with nothing to warn of.

## DangerButton

A button that destroys.

## FloatingPane

A window that floats over the page.

## Dialog

A question put in a window of its own.

## Doing

What a part lets the user do.

## Committing

What ends a decision.

## Shaping

How a part makes up its owner's room.

## Go

Ends the decision by going ahead.

## Cancel

Ends the decision by leaving it.

## Window

The room a part is shown in.
