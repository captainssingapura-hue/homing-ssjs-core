# The animating designs' fixture

## Stage

What is laid over a page's contents.

## Overlay

The marks laid over contents, drawn as a design draws them - some of them moving.

## Line

A line round what is marked: its ink, and how it moves.

## Area

The box over what is marked: its ground, and how it moves.

## Plate

A ground alone, which never moves.

## Strip

A band drawn with an image, beside how it moves.

## Pad

A plain place, cast as any component is.
