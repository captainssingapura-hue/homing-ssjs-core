# A small taxonomy, to derive semantic classes from

## Control

Something the user operates.

## Text

Words the user reads.

## PlainButton

Does one ordinary thing when pressed.

## Caption

Quiet words beside something.

## Roles

What a part does for its owner, here.

## Confirm

Does what the user decided.

## Title

Names what the owner is.

## Confirmation

Puts a decision to the user, to be confirmed.
