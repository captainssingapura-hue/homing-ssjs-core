# A trading desk, extending the hypothetical house

## Trading

Lets the user act on a trade.

## Side

Tells which side of a trade the owner is on.

## Buy

Commits to buying.

## Sell

Commits to selling.

## TradeButton

Commits the user to a trade.

## OrderTicket

Puts an order to the user: what it is, which side, and the commitment to buy or sell, or to leave it.
