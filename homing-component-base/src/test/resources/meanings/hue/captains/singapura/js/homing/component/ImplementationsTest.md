# A small house, for the implementations' gate

## Control

Something the user works.

## Button

Something the user presses to act.

## Container

Something that holds others.

## PlainButton

A button with no rank.

## DangerButton

A button that destroys.

## Icon

A mark that stands for something.

## Bar

A row of actions.

## Dialog

A question put to the user in a window of its own.

## IconButton

A button whose face is an icon.

## Strip

A row that holds a button to add with.

## Stray

A control the house never reads.

## Doing

What a part lets the user do.

## Act

One of a bar's actions.

## Acts

The actions a dialog offers.

## Symbol

What stands for the owner.

## Mark

The marks, alike but for their look: one class realizes every one.

## Star

A mark: a star.

## Moon

A mark: a moon.

## Badge

What shows the star.

## Picker

What shows any mark.

## Seal

The seals: one holds a part, so they are not alike but for their look.

## Knot

A seal holding an icon.
